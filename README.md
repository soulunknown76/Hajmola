# 🍲 EditMyDish  
### Futuristic Culinary Optimization Platform  

EditMyDish is a full-stack web application built for hackathon deployment.  
It allows users to analyze and modify recipe ingredient quantities while calculating a real-time deviation score to evaluate experimental impact.

The platform integrates authentication, MongoDB user management, and external API data via a secure backend proxy architecture.

---

## 🚀 Problem Statement

When modifying recipes, users often lack a measurable way to understand how ingredient changes affect overall balance.  
EditMyDish provides a structured deviation analysis model that quantifies ingredient variation.

---

## 🎯 Core Features

- 🔐 User Authentication (Register & Login)
- 📦 MongoDB-based user storage
- 📡 External API Integration (Cosylab Recipe API)
- 🧪 Ingredient Deviation Analysis Engine
- 📊 Real-time Stability Score Calculation
- 🛡 Backend Proxy Architecture (CORS-safe)
- 🎨 Futuristic UI Design

---

## 🧠 How It Works

1. User logs in
2. Backend fetches recipes via proxy
3. User selects a recipe
4. Ingredient quantities are editable

6. Stability classification is generated:
